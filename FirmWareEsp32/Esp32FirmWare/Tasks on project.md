**Последнее обновление:** 29.10.2026

## Цель проекта

Разработать модульную систему управления мобильными роботами:

- Получение телеметрии от ArduPilot.
- Двустороннее управление ровером через Wi-Fi.
- Визуализация состояния и траектории в Qt.
- Определение локальных координат без GPS.
- Движение второго модуля по траектории первого.
- Возможность подключения нескольких модулей Rover.

## Следующая задача

**Этап 2 — автоматическое обнаружение устройств в Wi-Fi-сети.**

Начать с изучения UDP Broadcast и разработки простого протокола обнаружения:

1. ESP32 отправляет `ROVER_DISCOVER`.
2. Qt принимает запрос.
3. Qt отвечает `ROVER_ACK`.
4. ESP32 определяет IP отправителя ответа.
5. ESP32 передаёт телеметрию на найденный адрес через Unicast.

Реализацию выполнять постепенно, отдельными классами, сохраняя работоспособность существующей системы.

**Ближайший практический шаг:** спроектировать класс обнаружения устройств и определить его интерфейс до внесения изменений в работающий код.
